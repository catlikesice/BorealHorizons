# Boreal Horizons – Travel Booking Platform

## Overview

Boreal Horizons is a travel booking platform designed to simplify
the discovery and booking of accommodation, rural tours,
sightseeing experiences and cultural attractions.

## Core Features

- Accommodation search and booking
- Rural tour and tour operator discovery
- Sightseeing and attraction ticketing
- Non-custodial cryptocurrency payment integration
- Travel communities and cultural content

## Technical Infrastructure

- GitHub – Source code and version control
- AWS Elastic Beanstalk – Application hosting
- AWS CodePipeline – Automated deployment
- Amazon S3 – Deployment artifact storage
- Node.js – Application runtime

## Development Status

The platform is currently in prototype development.

Manual and CodePipeline deployments have been completed
successfully. Automatic GitHub-triggered deployment is
currently being verified.

## Deployment Region

AWS Europe (Stockholm) – eu-north-1
